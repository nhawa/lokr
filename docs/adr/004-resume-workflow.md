# ADR-004: CV workflow

**Status: OPEN / owner decision required**

- **Option A, file-first (MVP recommendation):** upload PDF/DOCX, extract and review text, generate editable draft, export PDF, retain source version.
- **Option B, structured builder:** normalized experience/education/skills editor, template engine and generated versions. Stronger foundation but larger MVP scope.

Never treat file extraction as infallible. User must review extracted details and AI-generated claims.
