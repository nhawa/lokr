# LOK-010 — Constrained AI CLI Runner

## Goal
An optional isolated execution service used solely for supported official AI CLI integrations.

## Acceptance
- Runner separate from web app and off by default.
- Explicit binary/argv allowlist; no arbitrary shell execution or unsafe command interpolation.
- Authenticated local IPC (Unix socket preferred), deadlines, cancellation, size limits, redaction.
- Empty ephemeral workspace with tool/use privileges disabled by supported official mechanisms; refuse adapter if restrictions cannot be guaranteed.
- Never mount Docker socket or home directory by default; never request session cookies or scrape tokens.
- Structured-output schema validation and neutral error codes.
- Negative tests: injected job description command, missing binary, invalid auth, timeout, runner unavailable, excessive output, unavailable no-tools mode.
- Provider-specific official docs and terms checked before claiming subscription compatibility.
